## 功能

- **艾伦耶格尔遗忘曲线** 8 阶段智能复习排程
- **彩色分组文件夹** 按主题管理
- **桌面小组件** 今日复习一览，有任务变绿色
- **通知提醒 + 批量操作**

## 安装

从 [Releases](https://github.com/h0p3-cser/EbbinghausMemory/releases) 下载 DMG → 拖拽到 Applications → 右键打开即可。

**无需 Xcode，永不过期。**
